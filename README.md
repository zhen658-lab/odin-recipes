# odin-recipes
Odin Recipes

This is my first HTML project from The Odin Project.

In this project, I will create a simple recipe website that contains links to different recipes.

Skills Demonstrated

By completing this project, I will demonstrate the following skills:

- Creating an HTML boilerplate.
- Using HTML elements and tags.
- Creating headings and paragraphs.
- Adding links and images.
- Creating ordered and unordered lists.
- Organizing files and folders in a project.
